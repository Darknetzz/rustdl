Host app behavior

          
Applies to the rustdl desktop app on the PC running this server.

          
          
Lowers UI refresh rate while downloading or converting and uses denser queue rows sooner.

          
          
Hide the desktop window to the tray when minimizing or closing; downloads and encodes continue.

          
          
Background work priority

          
Lowers yt-dlp and ffmpeg priority so downloads and encodes are less likely to slow down other apps. Not a hard CPU/GPU cap.

          
          


          

          
Shared executables

          
Used by the downloader and Video Converter. Leave empty to use PATH.

          
          
          


          

          
GitHub releases

          
Personal access token for About → Check for updates when the repository is private. Read access to repository contents is enough.
